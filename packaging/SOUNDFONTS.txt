General MIDI SoundFonts

Place your uncompressed .sf2 SoundFonts here on Windows, beside the application.
Linux: $XDG_DATA_HOME/BitMusicVisualizer/soundfonts
       (default: ~/.local/share/BitMusicVisualizer/soundfonts)
macOS: ~/Library/Application Support/BitMusicVisualizer/soundfonts

Open a .mid or .midi file. The SoundFont list appears in the main player.
Select a bank to save the choice and restart the current MIDI from the beginning.
Browse... in this dropdown also selects an SF2 or SFLIST/JSON set from any folder.
Files stay in place; external selections are remembered by absolute path.
The folder button opens the resource folder; Refresh rereads its file list.
With no saved choice, the first bank alphabetically is used. A missing selected
bank is reported when opening MIDI; there is no startup warning.

SFLIST/JSON support is experimental.
To load several banks together, put a UTF-8 .sflist here with one SF2 path per
line, relative to the list. Select it like a bank. Later entries override matching
bank/program numbers; other instruments fall back to earlier entries. Blank
lines, # comments and quoted paths are accepted. Nested lists and foo_midi-style
JSON (.sflist or .json) with a soundFonts array of fileName objects also work.
Each list resolves paths relative to its own folder. BASSMIDI gain, channels and
patchMappings rules are reported as unsupported, not silently ignored.
Limits: 8 nesting levels, 64 KiB combined list text, 32 unique banks,
2 GiB per bank, 4 GiB per set. Large sets need
additional RAM and can take time to load.

Only uncompressed SF2 is supported. SF3, DLS and complete GS/XG device emulation are not
supported. MT-32 uses a separate engine and a ROM pair in roms/mt32.
No SoundFonts or ROMs are supplied/downloaded.
Check each bank's terms before redistributing it.
