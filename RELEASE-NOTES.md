# Bit Music Visualizer 0.7.3

Set the visualization window's width and height in screen pixels. Changes apply
immediately and the size is remembered on exit.

Click the **pencil**, then the **window-size icon next to the background eyedropper**.
The fields expand beside it; click again to hide them.
