# Bit Music Visualizer 0.11.1

Switch between stereo and mono views without opening the editor.

- **Shift+S** toggles Stereo / Mono visualization from either window. Audio stays unchanged, and **S** still controls Solo. Find the shortcut in the Stereo tooltip, F1 guide and README table.
