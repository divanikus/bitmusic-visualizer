# Bit Music Visualizer 0.8.0

- **Layout presets:** save the grid, card views, sizes, visibility and stereo mode.
  Select presets in the pencil editor; use the star to set or clear a default for
  the current chip configuration. Related presets can be adapted, such as NES to NES + VRC6.
- **Keyboard shortcuts:** control card views, channel mutes, visibility and playback.
  Use **0 / Alt+0** for Full mix and **Ctrl+Left / Ctrl+Right** for the L/R outputs.
  Press **F1** or click the main player's keyboard icon for the full list.
