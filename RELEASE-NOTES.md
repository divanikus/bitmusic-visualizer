# Bit Music Visualizer 0.7.1

## What's new

- **Multi-note keyboards:** highlight simultaneous notes, with the name and frequency of each note.
- **Sega PSG notes:** VGM/VGZ keyboards now use chip data, including all three tones in combined PSG cards.

Click the **pencil**, select a card and choose **View → Keyboard**.
Estimated mode still shows one approximate pitch, including Full mix.
